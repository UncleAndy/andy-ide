## Что не проверено здесь

В песочнице нет `DISPLAY`/`WAYLAND_DISPLAY`, `Xvfb` не запускается (XKB), поэтому всё, что видно только глазами, проверял пользователь:

- как выглядят цвета подсветки в тёмной и светлой схемах (тест проверяет только контраст светлых ключевых слов и то, что схемы различаются);
- перетаскивание и сброс панелей мышью;
- поведение окна при изменении размера, работа колеса мыши (синтетические события колеса в headless не двигают область прокрутки).

## Остаток по М1

1. Закрыто: курсоры вкладок восстанавливаются — позиция каретки пишется в `workspace.json`
   (`WorkspaceState::carets`, строка и колонка на каждый открытый файл).
2. Подсветка блоков кода в предпросмотре Markdown — ждёт `egui_commonmark` с колбэком (0.26 требует egui 0.37) или собственной отрисовки.
3. IME (ввод CJK) не поддержан.
4. Реестр горячих клавиш — одна функция `App::handle_keys`, а не таблица `(Modifiers, Key) → Command` из плана.

5. Покрытие тестами измерено 2026-10-31 на коммите `7a2ecc7`: 88,59 % строк по библиотечным
   крейтам (требование ТЗ — не ниже 60 %), 88,34 % строк по воркспейсу целиком. Самые слабые места —
   `ide-agents/src/bin/acp_test_agent.rs` (62,77 %, стенд-заглушка, не рабочий код), `ide-core/src/fs.rs`
   (75,00 %) и `ide-core/src/session.rs` (75,68 %). Инструмент и переменные `LLVM_COV`/`LLVM_PROFDATA`
   теперь стоят в `flake.nix`, так что замер повторяется одной командой из `nix develop`.

Ни один из пунктов остатка не мешает перейти к М2 (навигация через языковой сервер).
