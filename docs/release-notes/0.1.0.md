# andy-ide 0.1.0

An editor in a window, with the terminal, git and an agent beside the text. Rust, egui, no runtime to
install beyond the window system the desktop already has.

This is the first release. It is usable for a day's work — editing, navigation through a language
server, a shell, git, commits, an agent — and it is honest about what it does not do yet (the end of the
notes has the list).

## Download

| Platform | File | What it is |
|:--|:--|:--|
| Linux x86_64 | `andy-ide-0.1.0-x86_64-unknown-linux-gnu.tar.gz` | a tarball: the binary, the desktop file and the icon |
| Linux aarch64 | `andy-ide-0.1.0-aarch64-unknown-linux-gnu.tar.gz` | the same for 64-bit ARM |
| Linux, any desktop | `andy-ide-0.1.0-x86_64.AppImage` | one file, libraries inside, nothing to install |
| Windows x86_64 | `andy-ide-0.1.0-x86_64-pc-windows-msvc.zip` | `andy-ide.exe` and the licences |
| macOS (Apple silicon and Intel) | `andy-ide-0.1.0-universal.app.zip` | one `.app` for both architectures |

`SHA256SUMS` covers every file above.

## Running it

**Linux, AppImage**

```sh
chmod +x andy-ide-0.1.0-x86_64.AppImage
./andy-ide-0.1.0-x86_64.AppImage --project ~/some/project
```

The window system's own libraries — the GL driver, the Wayland or X11 client — are the host's, as they
must be; everything else travels inside the file. A desktop that has no FUSE can run it with
`--appimage-extract-and-run`.

**Linux, tarball**

```sh
tar -xzf andy-ide-0.1.0-x86_64-unknown-linux-gnu.tar.gz
install -m755 andy-ide-0.1.0-x86_64-unknown-linux-gnu/andy-ide ~/.local/bin/
```

The binary is built on Ubuntu 22.04 and needs glibc 2.35 or newer. Put `andy-ide.desktop` into
`~/.local/share/applications/` and `andy-ide.png` into `~/.local/share/icons/hicolor/512x512/apps/` if
you want it in the menu. `libxkbcommon`, `libwayland-client`, `libX11` and `libGL` have to be present —
every desktop has them, and a headless machine does not.

**Windows**

Unpack the zip and run `andy-ide.exe`. The build is not signed with a commercial certificate, so
SmartScreen says "Windows protected your PC" the first time: `More info` → `Run anyway`. The source and
the workflow that built the binary are in the repository.

**macOS**

Unpack the zip and drag `Andy IDE.app` wherever you keep applications. The bundle is signed ad-hoc (and
notarised only if the repository has an Apple Developer ID), so the first launch is refused with
"cannot be opened because the developer cannot be verified". Either:

```sh
xattr -d com.apple.quarantine "/Applications/Andy IDE.app"
```

or `System Settings` → `Privacy & Security` → `Open Anyway`. macOS 11 or newer.

## What it needs beside it

- **A language server** for the hints, the definitions and the diagnostics. Only `rust-analyzer` is
  expected to be found on `PATH` for Rust; pyright, gopls and clangd are looked up the same way, and
  each one's command can be replaced in `Settings` → `Tools`. Without a server the editor still edits,
  highlights and saves.
- **`git`**, for the branch and history commands that are not read through `gix`: `git` must be on
  `PATH` for a commit and a switch of branches.
- **An agent**, for the agent panel: an ACP-speaking program, configured in `.andy-ide/agents.toml` (or
  through `Settings` → `Agents`). The panel is empty and quiet without one.

## What is in the box

The window, the panels, the editor with tree-sitter highlighting for twelve languages, find and replace,
the language-server navigation, the terminal with several sessions, the git panel with staging, diffs and
history, the agent panel with notifications, the settings dialog, and the light and dark themes — the
whole list is in [`CHANGELOG.md`](https://github.com/UncleAndy/andy-ide/blob/main/CHANGELOG.md).

## What is not in it yet

- A file opened on a version from a commit, and a diff against an arbitrary base.
- Regular expressions in the project search.
- Reassigning the keys: the table is read-only in `Settings` → `Keys`.
- pyright, gopls and clangd are not bundled — they are looked up in `PATH`.
